# Фабрика видео-фактов (Reels / TikTok / Shorts)

Вертикальные видео 1080×1920 на русском: познавательные факты, AI-озвучка, анимированная типографика.
Видео собирается кодом в Remotion (`src/`), процесс — скриптами (`scripts/`).

Когда пользователь просит «сделай видео» / «новое видео» / «найди темы» — работай по процессу ниже, шаг за шагом.
**Если просят ролик о фильме (книге, сериале) — это стиль «Кино»: работай строго по его регламенту ниже (этапы 1–8, с подтверждением на каждом ⏸).**

## Процесс: от темы до готового ролика

### 1. Тема
- Ищи темы через WebSearch: вирусные научные новости недели, «удивительные факты о …», популярные вопросы.
- Хорошая тема = **парадокс или «не может быть»** (контринтуитивно), понятна без подготовки, раскрывается за 30–45 с.
- Записывай идеи в `topics/backlog.md` (тема · хук · почему зайдёт · статус). Сделанные — помечай ✅ со slug.
- Не повторяй темы, уже отмеченные ✅.

### 2. Факт-чек (обязательно)
- Каждый факт и каждое число — минимум 2 надёжных источника (научные издания, энциклопедии, университеты, NatGeo, NASA и т.п.).
- Спорное или «по некоторым данным» — либо убрать, либо сказать «около», «по оценкам».
- Источники — в поле `sources` сценария. Без источников видео не выпускать.

### 3. Сценарий → `videos/<slug>/script.json`
Создать: `npm run new -- <slug>` (копия `templates/script.example.json`, там все типы сцен).

Правила, по которым удерживается внимание:
- **Сцена 1 — `hook`**: 2–6 слов на экране, интрига за 1–2 с. Никаких «привет», «сегодня расскажу».
  Формулы: «У него три сердца», «Это запрещено в 12 странах», «Ты делаешь это неправильно».
- 5–8 сцен, **25–45 секунд** итого (~70–110 слов озвучки). `validateScript` предупредит, если длиннее.
- Каждая сцена — одна мысль. Каждые 3–5 с что-то новое на экране.
- Чередуй типы сцен: `fact`, `stat`, `compare`, `list` — не три `fact` подряд.
- **Последняя — `outro`**: вопрос в комментарии (вовлечение) + призыв подписаться. Можно закольцевать с хуком.
- `voice` — живая разговорная речь, короткие предложения. **Числа в `voice` — прописью** («пятьсот миллионов»), иначе голос ошибается в падежах. Цифры — только в полях для экрана (`value`, `text`).
- Текст на экране ≠ дословная озвучка: на экране суть (3–8 слов), голос рассказывает подробнее. Субтитры строятся из `voice` автоматически.
- `stat.value` — короткое число («500») + `suffix` (« млн»), иначе не влезет по ширине.
- `list` — до 4 пунктов, по 1–3 слова.
- `caption` — текст поста: 1–2 предложения + вопрос + эмодзи; `hashtags` — 5–8 (2–3 широких + узкие по теме).
- `theme`: `midnight` · `sunset` · `ocean` · `forest` · `mono` — подбирай под тему (космос → midnight, море → ocean, природа → forest, история → sunset/mono).

Типы сцен (поля см. `src/types.ts`): `hook`, `fact`, `stat`, `compare`, `list`, `outro`.

### 4. Черновик без озвучки (бесплатно)
```
npm run tts -- <slug> --provider=none
npm run render -- <slug> --preview        # 540×960, быстро
```
Проверь кадры сам: `remotion still` нужных кадров с `--props=out/<slug>/props.json` и посмотри картинки
(текст не вылезает, ничего не в нижних 20% и не у правого края, где интерфейс соцсети).

### 5. Озвучка + финальный рендер
```
npm run make -- <slug>                    # = tts + render
```
- TTS по умолчанию ElevenLabs (`eleven_multilingual_v2`, тайминги слов → точные субтитры). Ключ хранится как секрет окружения (прокси подставляет его сам) или в `ELEVENLABS_API_KEY`.
  Голос: `ELEVENLABS_VOICE_ID` или `script.tts.voiceId`.
- Альтернатива: `TTS_PROVIDER=openai` (`OPENAI_API_KEY`, тайминги слов оцениваются).
- Озвучка кэшируется по тексту: правка одной сцены переозвучивает только её.

### 6. Результат → `out/<slug>/`
`<slug>.mp4` (H.264, 30 fps), `cover.jpg` (обложка), `post.txt` (текст поста + хэштеги), `sources.txt`.
Отправь пользователю mp4, обложку и текст поста. Отметь тему ✅ в `topics/backlog.md`.

## Стиль «Хроника» (коллаж из архивных материалов)
Для историй брендов, изобретений, событий по годам. В сценарии `"style": "chronicle"`, образец — `templates/chronicle.example.json` (история Nike).
- Каждая сцена — «страница»: `year` (вырезанные буквы + линейка времени), `block` (цветная рваная бумага: red/orange/black/olive/blue/cream, `blockTop`), `clips` (фото/наклейки с координатами центра x,y и шириной w), `label` (печатная машинка), `headline`, `stat`, `stamp`, `note` (рукопись).
- Зоны кадра: год y≈230, картинки y≈380–1000, заголовок/число на цветной бумаге y≈1050–1280, субтитры с y=1345. Ниже 1500 — только фон.
- Длительность до ~60 с речи (у истории запас больше, чем у фактов).

### Картинки из архивов (бесплатно)
- `npm run img -- search "запрос"` — поиск на Wikimedia Commons (лицензия, автор, размер).
- `npm run img -- get <slug> "File:Имя.jpg" --as=имя` → `public/assets/<slug>/`, лицензия пишется в `credits.json`.
- Брать только Public domain / CC0 / CC BY / CC BY-SA. Для CC BY* указать автора: рендер создаёт `out/<slug>/credits.txt` — его в описание или первый комментарий.
- Wikimedia ограничивает частоту запросов: качать по одному, скрипт сам ждёт и повторяет.
- Вырезать белый фон у предмета (для наклейки) — PIL заливкой от краёв (см. историю `aj1-cut.png`), кадрировать — PIL `crop`.
- Не выдавать иллюстрацию за оригинал (напр. «вафельница», а не «та самая вафельница Бауэрмана»).
- Логотипы брендов — только в рассказе о бренде; ролик не должен выглядеть как официальная реклама.

## Стиль «Кино»: ежедневный ролик о фильме или сериале
Атмосферный пересказ без спойлеров, ~60 с, `"style": "cinema"`. Образцы: `templates/cinema.example.json`, `videos/shogun/` («Сёгун» — 3D; последний выпущенный — `videos/life-is-beautiful/`, 2D `scenes2d`).
**Это единый регламент: пользователь ничего не напоминает, все правила и решения записаны здесь. Новое правило или решение пользователя сразу дописывать в этот раздел.**

### Запуск
Пользователь пишет «ролик про <фильм>» (или «новый фильм», «следующий»). Тогда:
1. Если фильм не назван — предложить 3 кандидата (свежие/нашумевшие, не отмеченные ✅ в `topics/backlog.md`, сильный хук у каждого) и ждать выбора.
2. Если в `videos/<slug>/progress.md` уже есть чек-лист — продолжить с первого незакрытого этапа, не начинать заново.
3. Иначе: `npm run new -- <slug> --cinema` (slug — латиница), строка в бэклоге со статусом ✍️, и идти по этапам.

### Последовательность (⏸ = стоп, ждать «да» пользователя; без него дальше не идти)
Чек-лист этапов вести в `videos/<slug>/progress.md` (`- [x]`), коммитить и пушить после каждого этапа — сессии каждый день новые.
**Основная ветка — `claude/zen-bohr-8z10y2`** (ветка по умолчанию; с неё стартуют новые сессии). Пользователь разрешил: после каждого этапа коммит в рабочую ветку сессии **и сразу влить её в основную** (`git push origin HEAD:claude/zen-bohr-8z10y2`, перед этим `git fetch origin claude/zen-bohr-8z10y2 && git merge FETCH_HEAD`). Иначе следующая сессия не увидит сделанного и пользователю приходится напоминать.

| # | Этап | Что делаю | Что показываю / жду |
|---|---|---|---|
| 1 | **Факты** | Год, режиссёр/создатели, награды, платформа — каждый факт по 2 источникам → `sources` | — |

| 3 | **Раскадровка** | Таблица: сцена · фраза озвучки · что в кадре (место, персонажи, действие, свет/время суток) · ключевые слова (`emphasis`) | ⏸ таблица + **вопросы одним сообщением**: стиль рисовки (2D вектор / Пиксар), пресет шрифтов (не как в прошлом ролике), 2–3 варианта фразы для обложки, **попросить постер** в высоком разрешении |

| 5 | **Озвучка** | `npm run tts -- <slug>` (при нужде `npm run tighten`); сообщить фактический расход («💳 потрачено …») | ⏸ склейка голоса без видео (mp3) на прослушивание |

| 8 | **Публикация** | `videos/<slug>/posts.md` (3 платформы), `<slug>-tiktok-youtube.mp4`, бэклог ✅, коммит + пуш | отправить mp4, `cover.jpg`, tiktok-youtube.mp4, тексты постов |

Ничего в ElevenLabs не генерировать без подтверждённой сметы (этап 4), в том числе переозвучку отдельных сцен (`--only`): на каждую — своя смета.

### Текст рассказа (~60 с, 130–150 слов)
- Цель — чтобы ролик хотелось **сохранить или переслать другу**. Первая фраза — крючок (интрига, парадокс, сильная деталь), без «сегодня расскажу».
- Живой пересказ без «ты/вы» и официоза; конкретные яркие детали вместо общих слов; эмоциональные ставки героя; одна-две фразы «почему стоит посмотреть» (награда, рекорд, факт о съёмках); финальная фраза — запоминающаяся, такую хочется процитировать.
- **Без спойлеров**: только завязка первого акта.
- **Рассказ, а не протокол событий.** Цель — чтобы захотелось посмотреть фильм, а не пересказать его по эпизодам. Текст течёт как одна история: фразы связаны причиной и следствием («Но однажды…», «А тем временем…»), без рубленых скачков «событие. событие. событие.». Не нужно точно описывать каждую сцену фильма — берём 2–3 главных поворота, отношения героев и ставки; мелкие детали сюжета (точные сроки, предметы, процедуры) опускаем.
- **Обязательно: в конце — призыв к действию голосом** (последняя сцена, сразу после финальной фразы), напр. «Ставь лайк и подписывайся — впереди ещё кино» (как в «Сёгуне»); формулировку менять от ролика к ролику. Это единственное место, где можно обратиться к зрителю на «ты». На финальном кадре — плашка `poster.cta` («Подпишись»). Показывать призыв уже в тексте на согласование, не добавлять потом.
- Числа в `voice` — прописью.
- **Меньше точек** (замечание к «Ирландцу»): после каждой точки голос останавливается, и рубленые фразы звучат искусственно. Связывать мысли запятыми, «и», «а», «но», «когда» — одна-две фразы на сцену, речь течёт без лишних остановок.
- **Ударения**: слова, где голос может ошибиться, писать в `ttsText` со знаком ударения (U+0301), напр. «красишь дома́»; на экран идёт `voice` без знака.

### Темп: не дать перелистнуть
- **Каждая сцена двигает историю**: новое событие, решение героя, угроза или поворот. Никаких сцен-«открыток» с перечислением обстановки (в «Рипли» «Атрани. Море… вилла… мартини…» вышло скучно). Атмосферу даёт картинка, а не фраза.
- Сцена — 3–6 с речи (максимум ~7 с), плотность ≥ 2,5 слова/с. Длинную сцену делить на две с разными кадрами.
- Не больше одной драматической паузы (многоточие) на ролик; перечисления через «…» не использовать.
- Активные глаголы, настоящее время, короткие фразы; в середине — крючок на продолжение («И тут…», «Но есть одно но»).
- **Напряжение, а не спокойный пересказ** (замечание к «Переводчику»): каждые ~8–10 с — открытая петля, которая тянет дальше: вопрос («Его преступление?»), противопоставление («Ему проще бросить. Он не бросает.»), угроза или тикающие часы, рваный ритм из 1–3 слов в кульминации («Засада. Отряда больше нет.»). Хук — с конца истории (ставки), а не с начала.
- Между сценами пауза **6 кадров** (`pause`; вместе с AUDIO_DELAY ≈0,33 с тишины), растворение 24 кадра; 18 кадров пользователь счёл затянутыми («Жизнь прекрасна»).

### Голос
- Рассказчик: `tts.voiceId` `6A9D8WSMm4rFsg2DWFeE` (основной; Иван — `1kb4Md8n0kMNktygYhDF`), модель `eleven_v4`.
- Живо и выразительно: `stability` ≈0.3–0.4, `style` ≈0.4–0.6, `similarity_boost` 0.8; короткие фразы, тире, вопросы.
- Аудиотеги — в `ttsText` сцены (на экран идёт `voice`). **Дозированно**: не больше одного мягкого тега на сцену и не в каждой сцене; без «ominous», «suspicious», «intimate» подряд (в «Рипли» вышло наиграно); **[whispers] почти не использовать**; замедляющие теги ([dreamy], [slowly]) не использовать. Теги замедляют речь — закладывать запас.
- Ролик (вместе с постером) должен укладываться в 60 с: постер `poster.seconds: 2.5`, темп обычно 1.2 («Переводчик», «Жизнь прекрасна»).
- Если голос медленный — `tts.tempo` (напр. 1.1, как в «Сёгуне») + `npm run tighten -- <slug>`, без новой генерации. После каждого повторного `tts` — снова `tighten`.
- Громкость: голос −16 LUFS (tts), финальный mp4 −14 LUFS.

### Звук и музыка
**Только голос.** Без музыки и эффектов (нет `musicPrompt`, `sfx`; `npm run sound` не запускать). Музыку пользователь добавляет сам в редакторе.

### Картинка
- **Стиль рисовки — один из двух, спросить на раскадровке** (решение пользователя, «Ирландец»; других стилей не предлагать):
  1. **2D вектор** — как в «Переводчике» и «Жизнь прекрасна»: `scenes2d/<slug>.js` на ядре `scenes2d/core.js` (персонажи `person()` с крупной головой и лицом анфас, градиенты, свечение, мягкие тени, `setProportions` как в «Жизнь прекрасна»). В сценарии `"art": "vector"`; клипы — `npm run scenes3d -- <slug>` (для vector он сам берёт scenes2d, в облаке ~0,2 с/кадр), черновики — `npm run scenes3d -- <slug> --stills`.
  2. **Пиксар** — настоящий 3D (three.js, `scenes3d/<slug>.js`): мягкие тени, GTAO, Bokeh, bloom, ACES, тёплый ключевой + холодный контровой свет. Финальный рендер — на MacBook.
  **Не использовать** SVG-декорации Remotion (`src/cinema/Sets*.tsx`, стиль «Снов поездов»/«Рипли»): пользователь отказался от этого стиля, файлы оставлены только для пересборки старых роликов. Диораму тоже не предлагать.
  Образцы — `lab/styles/refs/` (`pixar.jpg`, `vector.jpg`).
- Сцены рисовать **заново под сюжет каждого фильма** (2D — ядро `scenes2d/core.js` и функции из прошлых `scenes2d/*.js`; 3D — ядро `scenes3d/core.js`). Кадры из фильма не используем. 3D-модели персонажей пока не используем (фигурки из примитивов).
- Текст на экране — **только кинетическая типографика из озвучки** (`src/cinema/Kinetic.tsx`): слова появляются под голос и копятся блоком (до ~9 слов / 4 строк), слова не переносятся по буквам. Три роли шрифтов: рукописный (ключевые слова из `emphasis`), основной, капители (служебные слова).
- **Шрифты в каждом ролике разные** (`"fonts"`): `classic` (был в «Снах поездов», «Рипли»), `noir` (был в «Сёгуне»), `futura` (Jost 700 вместо Futura + Great Vibes вместо Corinthia — у Corinthia нет кириллицы; был в «Жизнь прекрасна»), `modern`, `display`, `hand` или своя тройка `{script, serif, caps}`. Не повторять пресет предыдущего ролика. Новые шрифты с кириллицей (OFL): `npm pack @fontsource/<имя>` → `public/fonts/` + строка в `src/fonts.ts`.
- **Фото-стикеры актёров** (просьба пользователя, «Ирландец»): в сцене, где голос называет актёров/создателей, — их реальные фото с Wikimedia Commons (только свободные лицензии, автор → `credits.txt`), без фона (rembg), белая обводка и тень как у наклейки, без подложки (прямо поверх фона сцены); появляются по одному под имя (pop-in), слегка покачиваются. Остальные сцены — рисованные.
- Вид: лёгкое неподвижное зерно, виньетка, каше. **Мерцание, дрожание кадра, пылинки — выключены.** `"film": true` — только по просьбе пользователя.
- **Последний кадр — официальный постер** (`"poster": {src, titleRu, titleEn, year, cta: "Подпишись"}`): постер по центру, под ним название (Manrope 800, не крупно), «English title · год», плашка-призыв цвета `accent` с сердцем. Постер присылает пользователь, не искать в низком качестве.

### Обложка (единый шаблон для ленты)
- `"instaCover": {top, main, base, glows}` → композиция `InstaCover` (`src/cinema/InstaCover.tsx`), рендер кладёт в `cover.jpg` (отдельно — `npm run insta -- <slug>`). Старый `CinemaCover` не использовать.
- Текст всегда на одной высоте и одного размера: верхняя строка Montserrat Light в разрядку (y≈700), главная фраза Playfair Display Black 150px с y≈800, 1–2 строки, ≤ ~9 букв в строке; зона 3:4 (y 240–1680). Меняются только слова и палитра (`base`, `glows`).
- Фраза — хук из фильма, **без названия**; предложить 2–3 варианта на раскадровке.

### Тексты постов → `videos/<slug>/posts.md` (образец — `videos/shogun/posts.md`)
- **Название фильма/сериала нигде не писать** (ни по-русски, ни по-английски, ни в хэштегах) — вместо него «Название фильма (сериала) в конце видео 🎬».
- Не писать про спойлеры («без спойлеров» и т.п.). **Не использовать длинное тире «—»** (запятые, двоеточия, точки).
- **Instagram**: подпись + «Сохрани, чтобы не забыть посмотреть 📌» + вопрос; **≤ 5 хэштегов**. Обложку загрузить `cover.jpg`, видео `<slug>.mp4`.
- **TikTok**: текст с ключевыми словами для поиска (жанр, место, эпоха, «что посмотреть», «сериал про …») + 3–5 хэштегов. Видео `<slug>-tiktok-youtube.mp4`, обложка — первый кадр.
- **YouTube Shorts**: название до 100 символов с `#shorts` + описание. Видео `<slug>-tiktok-youtube.mp4`, обложка — первый кадр.
- `<slug>-tiktok-youtube.mp4`: TikTok и Shorts не дают загрузить обложку, поэтому `cover.jpg` ставится первыми 2 кадрами (0,07 с) перед видео (ffmpeg concat).

### Команды
`npm run new -- <slug> --cinema` → `npm run cost -- <slug>` → `npm run tts -- <slug>` (`--only=2,5` — отдельные сцены) → `npm run tighten -- <slug>` → `npm run stills -- <slug> …` → `npm run render -- <slug>` → `npm run insta -- <slug>`.

**3D (Пиксар):**
- План сцены — функция в `scenes3d/<slug>.js`, возвращает `{cam, focus, update(t)}`; имя плана = `set` сцены в сценарии.
- Черновые кадры: `npm run scenes3d -- <slug> --stills [--at=0.5]` → `out/<slug>/scenes3d/` (540×960, ~5 с/кадр в облаке).
- Клипы: `npm run scenes3d -- <slug> [--only=2,5]` → `public/generated/<slug>/clips/scene-N.mp4`; `npm run render` сам подставляет их вместо 2D.
- Финальные клипы — на MacBook пользователя (GPU, на macOS включается сам, иначе `SCENES3D_GPU=1`); в облаке ~13 с/кадр — только проверка. Озвучку (`public/generated/<slug>/*.mp3` + `manifest.json`) коммитить `git add -f`.
- На Mac без Playwright: `npm install --no-save playwright@<версия>` перед `npm run scenes3d`; первый `npm run render` на новом компьютере требует интернет.
- Лаборатория стилей: `lab/styles/scene.js` (3D, `?style=pixar|diorama|…`), `lab/styles/flat.html` (2D, `?style=vector|…`); кадр — `node lab/styles/shot.cjs pixar diorama 2d-vector --w=1080 --h=1920`; анимация → mp4 — `lab/styles/frames.cjs` (`window.renderAt(t)`). 2D — Chromium с `--disable-gpu`, 3D — WebGL через SwiftShader.

## Технические заметки
- Безопасная зона: контент в `Stage` (y 220–1180), субтитры y≈1230–1490; низ (>1500) и правый край (~150px) закрывает интерфейс TikTok/Reels.
- Шрифты: Unbounded (заголовки) и Manrope (текст), кириллица, файлы в `public/fonts/` (OFL).
- Музыка (необязательно): положить mp3 в `public/music/`, в сценарии `"music": "music/file.mp3"`, `"musicVolume": 0.08`. Только музыку с лицензией (или добавлять трендовый звук уже в приложении при публикации).
- Предпросмотр в браузере: `npm run studio`.
- Тип-чек: `npm run check`.
- Проверочные кадры одной сборкой: `npm run stills -- <slug> 120 300 450` → `out/<slug>/stills/` (нужен `out/<slug>/props.json` от рендера).
- Node `fetch` в облачной сессии ходит через прокси только с `NODE_USE_ENV_PROXY=1` (уже прописано в npm-скриптах).
- Рендер использует Chromium из `/opt/pw-browsers` если он есть (`REMOTION_BROWSER` переопределяет).
- Remotion бесплатен для физлиц и компаний до 3 человек; дальше нужна компанейская лицензия.
