# Фабрика видео-фактов (Reels / TikTok / Shorts)

Вертикальные видео 1080×1920 на русском: познавательные факты, AI-озвучка, анимированная типографика.
Видео собирается кодом в Remotion (`src/`), процесс — скриптами (`scripts/`).

Когда пользователь просит «сделай видео» / «новое видео» / «найди темы» — работай по процессу ниже, шаг за шагом.
**Если просят ролик о фильме (книге, сериале) — это стиль «Кино»: работай по его разделу ниже, с согласованием каждого этапа.**

## Процесс: от темы до готового ролика

### 1. Тема
- Ищи темы через WebSearch: вирусные научные новости недели, «удивительные факты о …», популярные вопросы.
- Хорошая тема = **парадокс или «не может быть»** (контринтуитивно), понятна без подготовки, раскрывается за 30–45 с.
- Записывай идеи в `topics/backlog.md` (тема · хук · почему зайдёт · статус). Сделанные — помечай ✅ со slug.
- Не повторяй темы, уже отмеченные ✅.

### 2. Факт-чек (обязательно)
- Каждый факт и каждое число — минимум 2 надёжных источника (научные издания, энциклопедии, университеты, NatGeo, NASA и т.п.).
- Спорное или «по некоторым данным» — либо убрать, либо сказать «около», «по оценкам».
- Источники — в поле `sources` сценария. Без источников видео не выпускать.

### 3. Сценарий → `videos/<slug>/script.json`
Создать: `npm run new -- <slug>` (копия `templates/script.example.json`, там все типы сцен).

Правила, по которым удерживается внимание:
- **Сцена 1 — `hook`**: 2–6 слов на экране, интрига за 1–2 с. Никаких «привет», «сегодня расскажу».
  Формулы: «У него три сердца», «Это запрещено в 12 странах», «Ты делаешь это неправильно».
- 5–8 сцен, **25–45 секунд** итого (~70–110 слов озвучки). `validateScript` предупредит, если длиннее.
- Каждая сцена — одна мысль. Каждые 3–5 с что-то новое на экране.
- Чередуй типы сцен: `fact`, `stat`, `compare`, `list` — не три `fact` подряд.
- **Последняя — `outro`**: вопрос в комментарии (вовлечение) + призыв подписаться. Можно закольцевать с хуком.
- `voice` — живая разговорная речь, короткие предложения. **Числа в `voice` — прописью** («пятьсот миллионов»), иначе голос ошибается в падежах. Цифры — только в полях для экрана (`value`, `text`).
- Текст на экране ≠ дословная озвучка: на экране суть (3–8 слов), голос рассказывает подробнее. Субтитры строятся из `voice` автоматически.
- `stat.value` — короткое число («500») + `suffix` (« млн»), иначе не влезет по ширине.
- `list` — до 4 пунктов, по 1–3 слова.
- `caption` — текст поста: 1–2 предложения + вопрос + эмодзи; `hashtags` — 5–8 (2–3 широких + узкие по теме).
- `theme`: `midnight` · `sunset` · `ocean` · `forest` · `mono` — подбирай под тему (космос → midnight, море → ocean, природа → forest, история → sunset/mono).

Типы сцен (поля см. `src/types.ts`): `hook`, `fact`, `stat`, `compare`, `list`, `outro`.

### 4. Черновик без озвучки (бесплатно)
```
npm run tts -- <slug> --provider=none
npm run render -- <slug> --preview        # 540×960, быстро
```
Проверь кадры сам: `remotion still` нужных кадров с `--props=out/<slug>/props.json` и посмотри картинки
(текст не вылезает, ничего не в нижних 20% и не у правого края, где интерфейс соцсети).

### 5. Озвучка + финальный рендер
```
npm run make -- <slug>                    # = tts + render
```
- TTS по умолчанию ElevenLabs (`eleven_multilingual_v2`, тайминги слов → точные субтитры). Ключ хранится как секрет окружения (прокси подставляет его сам) или в `ELEVENLABS_API_KEY`.
  Голос: `ELEVENLABS_VOICE_ID` или `script.tts.voiceId`.
- Альтернатива: `TTS_PROVIDER=openai` (`OPENAI_API_KEY`, тайминги слов оцениваются).
- Озвучка кэшируется по тексту: правка одной сцены переозвучивает только её.

### 6. Результат → `out/<slug>/`
`<slug>.mp4` (H.264, 30 fps), `cover.jpg` (обложка), `post.txt` (текст поста + хэштеги), `sources.txt`.
Отправь пользователю mp4, обложку и текст поста. Отметь тему ✅ в `topics/backlog.md`.

## Стиль «Хроника» (коллаж из архивных материалов)
Для историй брендов, изобретений, событий по годам. В сценарии `"style": "chronicle"`, образец — `templates/chronicle.example.json` (история Nike).
- Каждая сцена — «страница»: `year` (вырезанные буквы + линейка времени), `block` (цветная рваная бумага: red/orange/black/olive/blue/cream, `blockTop`), `clips` (фото/наклейки с координатами центра x,y и шириной w), `label` (печатная машинка), `headline`, `stat`, `stamp`, `note` (рукопись).
- Зоны кадра: год y≈230, картинки y≈380–1000, заголовок/число на цветной бумаге y≈1050–1280, субтитры с y=1345. Ниже 1500 — только фон.
- Длительность до ~60 с речи (у истории запас больше, чем у фактов).

### Картинки из архивов (бесплатно)
- `npm run img -- search "запрос"` — поиск на Wikimedia Commons (лицензия, автор, размер).
- `npm run img -- get <slug> "File:Имя.jpg" --as=имя` → `public/assets/<slug>/`, лицензия пишется в `credits.json`.
- Брать только Public domain / CC0 / CC BY / CC BY-SA. Для CC BY* указать автора: рендер создаёт `out/<slug>/credits.txt` — его в описание или первый комментарий.
- Wikimedia ограничивает частоту запросов: качать по одному, скрипт сам ждёт и повторяет.
- Вырезать белый фон у предмета (для наклейки) — PIL заливкой от краёв (см. историю `aj1-cut.png`), кадрировать — PIL `crop`.
- Не выдавать иллюстрацию за оригинал (напр. «вафельница», а не «та самая вафельница Бауэрмана»).
- Логотипы брендов — только в рассказе о бренде; ролик не должен выглядеть как официальная реклама.

## Стиль «Кино» (атмосферный пересказ фильма/истории)
Для пересказов фильмов и книг без спойлеров. В сценарии `"style": "cinema"`, образец — `templates/cinema.example.json` («Сны поездов»).

### Согласование — каждый этап до перехода к следующему
Пользователь подтверждает каждый шаг, чтобы ничего не перегенерировать:
1. **Текст рассказа** (см. ниже) — правки, пока не утвердит.
2. **Раскадровка**: таблица сцен — какая фраза озвучки на какой сцене, что в кадре (место, персонажи, действие, свет/время суток), ключевые слова. Подтвердить до рисования сцен.
3. **Постер**: попросить у пользователя официальную обложку в высоком разрешении (он пришлёт сам), не искать в низком качестве.
4. **Смета ElevenLabs** перед КАЖДОЙ генерацией: `npm run cost -- <slug>` → показать, что генерируем, сколько кредитов уйдёт и сколько останется. Без подтверждения ничего в ElevenLabs не генерировать. После — сообщить фактический расход (tts печатает «💳 потрачено …»).
5. **Голос**: после озвучки отправить склейку голоса (без видео) на прослушивание.
6. **Черновые кадры** сцен (`npm run stills`) — показать, затем финальный рендер.

### Текст рассказа (~60 с, 130–150 слов)
- Цель — чтобы ролик сразу хотелось **сохранить или переслать другу**. Первая фраза — крючок (интрига, парадокс, сильная деталь), без «сегодня расскажу».
- **Рассказ, а не протокол событий.** Цель — чтобы захотелось посмотреть фильм, а не пересказать его по эпизодам. Текст течёт как одна история: фразы связаны причиной и следствием («Но однажды…», «А тем временем…»), без рубленых скачков «событие. событие. событие.». Не нужно точно описывать каждую сцену фильма — берём 2–3 главных поворота, отношения героев и ставки; мелкие детали сюжета (точные сроки, предметы, процедуры) опускаем.
- Живой интересный пересказ, без «ты/вы» и официоза; конкретные яркие детали вместо общих слов; эмоциональные ставки героя; одна-две фразы «почему это стоит посмотреть»; финальная фраза — запоминающаяся, такую хочется процитировать.
- Без спойлеров: только завязка первого акта. Факты (год, режиссёр, награды) — по 2 источникам.
- **Обязательно: в конце — призыв к действию голосом** (последняя сцена, сразу после финальной фразы), напр. «Ставь лайк и подписывайся — впереди ещё кино» (как в «Сёгуне»); формулировку менять от ролика к ролику. Это единственное место, где можно обратиться к зрителю на «ты». На финальном кадре — плашка `poster.cta` («Подпишись»). Показывать призыв уже в тексте на согласование, не добавлять потом.

### Темп — не дать перелистнуть
- **Каждая сцена двигает историю**: новое событие, решение героя, угроза или поворот. Никаких сцен-«открыток», где просто перечисляется обстановка (в «Рипли» сцена «Атрани. Море… вилла… мартини…» вышла затянутой и скучной — так не делать). Атмосферу даём картинкой, а не отдельной фразой.
- Сцена — 3–6 с речи (максимум ~7 с), плотность ≥ 2,5 слова в секунду. Длинную сцену делить на две с разными кадрами.
- Многоточия и паузы в голосе — не больше одной драматической паузы на ролик. Перечисления через «…» не использовать.
- Активные глаголы, настоящее время, короткие фразы; в середине — «крючок» на продолжение («И тут…», «Но есть одно но»).
- Перед согласованием текста прочитать его как зритель: если на какой-то фразе хочется листать дальше — переписать или вырезать.

### Голос — главное
- Делать голос максимально живым и выразительным, чтобы не уснуть: подбирать `tts.settings` (ниже `stability` ≈0.3–0.4 = больше эмоций, `style` ≈0.4–0.6), темп `tts.speed`, короткие фразы, паузы через многоточия/тире, вопросы. Можно пробовать `eleven_v3` с аудиотегами ([whispers], [excited] и т.п.) — только после согласования.
- Голос рассказчика: `tts.voiceId` (новый основной — `6A9D8WSMm4rFsg2DWFeE`; Иван — `1kb4Md8n0kMNktygYhDF`).
- Модель: `eleven_v4` (самая выразительная, тайминги слов работают). Аудиотеги пишутся в поле сцены `ttsText` (на экран идёт `voice`).
- **Аудиотеги — дозированно.** В «Рипли» с середины до конца вышло слишком наиграно: не больше одного мягкого тега на сцену и не в каждой сцене; без «ominous», «suspicious», «intimate» подряд. **Шёпот ([whispers]) почти не использовать.**
- Теги замедляют речь: закладывать запас по длительности. Не использовать замедляющие теги ([dreamy], [slowly] и т.п.).

### Звук и музыка
- **Только голос.** Музыку и звуковые эффекты не используем (нет `musicPrompt`, нет `sfx`; `npm run sound` не запускать). Музыку пользователь добавляет сам в редакторе.
- Громкость: голос нормализуется к −16 LUFS (tts), финальный mp4 → −14 LUFS.

### Картинка
- Сцены — детальные анимированные планы (`set`, `src/cinema/Sets.tsx`) с персонажами (`src/cinema/people.tsx`: ходьба, рубка, сидя) и деталями (`src/cinema/kit.tsx`): `station`, `valley`, `logging`, `bridge`, `cabin`, `seasons`, `campfire`, `lake`, `dawn`. Для нового фильма — рисовать новые сцены под его сюжет. Кадрирование — `CAMERA` в Sets.tsx. Кадры из фильма в сценах не используем.
- Текст на экране — **только кинетическая типографика из озвучки** (`src/cinema/Kinetic.tsx`), слова появляются ровно под голос и копятся в кадре блоком (до ~9 слов / 4 строк). Три роли шрифтов: рукописный (ключевые слова из `emphasis`, росчерк), основной (текст), капители (служебные слова). Слова не переносятся по буквам.
- **Шрифты в каждом ролике разные** — поле `"fonts"` в сценарии: пресет `classic` (Great Vibes · Cormorant Garamond · Oswald, был в «Снах поездов» и «Рипли»), `noir` (Marck Script · Playfair Display · Tenor Sans), `modern` (Great Vibes · Jost · Tenor Sans), `display` (Marck Script · Yeseva One · Jost), `hand` (Caveat · Cormorant Garamond · Tenor Sans) или своя тройка `{script, serif, caps}`. Подбирать под настроение фильма и не повторять пресет предыдущего ролика; на этапе раскадровки предложить пользователю. Новые шрифты с кириллицей (OFL) — `npm pack @fontsource/<имя>` → `public/fonts/` + строка в `src/fonts.ts`.
- **Последний кадр — официальная обложка фильма** (`"poster": {src, titleRu, titleEn, year}`): постер по центру, под ним название на русском (Manrope 800, жирный без засечек, не крупно) и «English title · год». Постер присылает пользователь (высокое разрешение) — попросить его на этапе раскадровки; файл в `public/assets/<slug>/poster.jpg`.
- Темп: пауза между сценами ~18 кадров ≈ 0,6 с (`pause`), растворение 24 кадра. Длинные паузы пользователю кажутся затянутыми.
- Вид: лёгкое неподвижное зерно, виньетка, каше. **Мерцание яркости, дрожание кадра и пылинки выключены** (пользователю мешало «мерцание»). Старый плёночный режим — `"film": true`, только если пользователь попросит.
- **Обложка — единый шаблон для всех роликов** (`"instaCover": {top, main, base, glows}` → композиция `InstaCover`, `src/cinema/InstaCover.tsx`; рендер кладёт её в `cover.jpg`, отдельно — `npm run insta -- <slug>`). Пользователь хочет, чтобы в ленте обложки стояли ровно: **текст всегда на одной высоте и одного размера** (верхняя строка Montserrat Light в разрядку y≈700, главная фраза Playfair Display Black 150px с y≈800, 1–2 строки, ≤ ~9 букв в строке), в зоне 3:4 (y 240–1680). От ролика к ролику меняются только слова и палитра (`base`, `glows`). Фраза — хук из фильма, **без названия**; предложить 2–3 варианта. Старый `CinemaCover` (`"cover"`) не использовать.
- **Финальный кадр с постером** — `poster.cta` («Подпишись») рисует под названием плашку-призыв цвета `accent` с сердцем.

### Команды
`npm run cost -- <slug>` (смета) → `npm run tts -- <slug>` → `npm run stills -- <slug> …` → `npm run render -- <slug>`.
- Сцены «Снов поездов» в `src/cinema/Sets.tsx` — образец; для нового фильма рисовать свои сцены под его сюжет (можно переиспользовать детали из kit.tsx и персонажей из people.tsx).

### 3D-сцены (стиль Пиксар) → клипы
- Сцены фильма — `scenes3d/<slug>.js` (ядро `scenes3d/core.js`: персонажи `person()`, огонь `fire()`, пар `steam()`, постобработка, камера from→to). Каждый план — функция, возвращает `{cam, focus, update(t)}`; имя плана = `set` сцены в сценарии.
- Черновые кадры: `npm run scenes3d -- <slug> --stills [--at=0.5]` → `out/<slug>/scenes3d/` (540×960, ~5 с/кадр в облаке).
- Клипы: `npm run scenes3d -- <slug> [--only=2,5]` → `public/generated/<slug>/clips/scene-N.mp4` (длина = озвучка + пауза + растворение из manifest). `npm run render` сам подставляет клипы вместо 2D-декораций.
- **Финальный рендер 3D — на MacBook пользователя** (GPU; на macOS включается сам, иначе `SCENES3D_GPU=1`). В облаке ~13 с/кадр — только кадры для проверки. Озвучку (`public/generated/<slug>/*.mp3` + `manifest.json`) коммитить в ветку принудительно (`git add -f`), иначе на Mac её не будет.
- Ужать озвучку без новой генерации: `npm run tighten -- <slug>` (`tts.tempo`, напр. 1.1 — atempo без смены тона + обрезка хвостов; тайминги слов пересчитываются). После повторного `tts` запускать снова.

### Публикация (Instagram, TikTok, YouTube — одно и то же видео)
- **В текстах постов не писать про спойлеры («без спойлеров» и т.п.) и не использовать длинное тире «—»** (запятые, двоеточия, точки).
- **Название фильма/сериала в текстах постов, названиях и хэштегах не писать** (ни по-русски, ни по-английски): оно показывается в конце ролика, это стимул досмотреть. Вместо этого фраза «Название фильма (сериала) в конце видео 🎬».
- Тексты — `videos/<slug>/posts.md`, отдельно под каждую платформу: Instagram — подпись + «сохрани» + вопрос, **не больше 5 хэштегов**; TikTok — текст с ключевыми словами для поиска (жанр, место, эпоха, «что посмотреть», «сериал про …») + 3–5 хэштегов; YouTube Shorts — название до 100 символов с `#shorts` + описание.
- Обложка: Instagram позволяет загрузить `cover.jpg`; TikTok и Shorts — только выбрать кадр. Поэтому для них делать `<slug>-tiktok-youtube.mp4` с обложкой первыми 2 кадрами (ffmpeg concat, 0,07 с) и выбирать первый кадр.
- Если в CLAUDE.md-окружении нет Playwright в зависимостях (на Mac), перед `npm run scenes3d` выполнить `npm install --no-save playwright@<версия>`; первый `npm run render` на новом компьютере требует интернет (Remotion скачивает браузер).

### Выбранные стили рисовки для «Кино» (решение пользователя)
Каждый пересказ фильма собираем в **одном из трёх стилей** — какой именно, спросить у пользователя при раскадровке. **Не делать всё в Пиксаре по умолчанию**: «Сёгун» был в Пиксаре, пользователь хочет пробовать и 2D-вектор (он рендерится прямо в облаке за минуты, без MacBook).
Образцы кадров — `lab/styles/refs/` (`pixar.jpg`, `diorama.jpg`, `vector.jpg`; все 10 проб — `all-10-styles.jpg`).
1. **Пиксар** — настоящий 3D (three.js): мягкие тени, затенение в углах (GTAO), глубина резкости (Bokeh), свечение (bloom),
   ACES-тонмаппинг, тёплый ключевой свет + холодный контровой, кожа с sheen. Самый близкий к мультфильмам.
2. **Диорама** — та же 3D-сцена как комната-коробочка сверху, tilt-shift размытие краёв. Хороша для заставок/переходов.
3. **2D вектор** — SVG-иллюстрация с градиентами, свечением и виньеткой, «детская книжка». Самый быстрый рендер.
- Код проб: `lab/styles/scene.js` (3D, `?style=pixar|diorama|…`), `lab/styles/flat.html` (2D, `?style=vector|…`).
  Кадр: `node lab/styles/shot.cjs pixar diorama 2d-vector --w=1080 --h=1920` → `lab/styles/out/`.
  Анимация кадр за кадром → mp4: `lab/styles/frames.cjs` (сцена отдаёт `window.renderAt(t)`).
  Для 2D-страниц Chromium запускается с `--disable-gpu`, для 3D — WebGL через SwiftShader (в облаке нет видеокарты).
- Персонажи пока собраны из примитивов (похожи на игрушечные фигурки). 3D-модели персонажей решили пока не использовать.
- Скорость 3D в облаке: ~13 с/кадр 1080×1920 (Пиксар), ~3 с в черновике 540×960. На MacBook Pro M4 Pro пользователя
  (GPU) — ожидаемо доли секунды: длинные 3D-рендеры лучше делать на нём.
- Сцены под каждый фильм рисовать заново под его сюжет (комната с ребёнком и банкой светлячков — только образец стиля).

## Технические заметки
- Безопасная зона: контент в `Stage` (y 220–1180), субтитры y≈1230–1490; низ (>1500) и правый край (~150px) закрывает интерфейс TikTok/Reels.
- Шрифты: Unbounded (заголовки) и Manrope (текст), кириллица, файлы в `public/fonts/` (OFL).
- Музыка (необязательно): положить mp3 в `public/music/`, в сценарии `"music": "music/file.mp3"`, `"musicVolume": 0.08`. Только музыку с лицензией (или добавлять трендовый звук уже в приложении при публикации).
- Предпросмотр в браузере: `npm run studio`.
- Тип-чек: `npm run check`.
- Проверочные кадры одной сборкой: `npm run stills -- <slug> 120 300 450` → `out/<slug>/stills/` (нужен `out/<slug>/props.json` от рендера).
- Node `fetch` в облачной сессии ходит через прокси только с `NODE_USE_ENV_PROXY=1` (уже прописано в npm-скриптах).
- Рендер использует Chromium из `/opt/pw-browsers` если он есть (`REMOTION_BROWSER` переопределяет).
- Remotion бесплатен для физлиц и компаний до 3 человек; дальше нужна компанейская лицензия.
